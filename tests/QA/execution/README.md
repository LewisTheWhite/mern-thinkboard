# QA Execution Phase

This folder contains deliverables and logs from the execution phase of the Software Testing Life Cycle (STLC).

## Contents
- Test execution logs
- Bug reports
- Test run summaries
- Screenshots and evidence
- Test execution metrics

## Key Activities
1. Execute test cases as per test plan
2. Document results and findings
3. Report bugs with detailed information
4. Track test progress
5. Collect evidence (screenshots, logs)
6. Update test case status

## Test Execution Checklist
- [ ] Test environment ready
- [ ] Test data prepared
- [ ] Test cases reviewed
- [ ] Tester assigned
- [ ] Baseline build tested
- [ ] All tests executed
- [ ] Results documented
- [ ] Bugs reported
- [ ] Test summary prepared
