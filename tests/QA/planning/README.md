# QA Planning Phase

This folder contains deliverables from the planning phase of the Software Testing Life Cycle (STLC).

## Contents
- Test Strategy document
- Test Plan document
- Requirements traceability matrix (RTM)
- Risk assessment and mitigation plan
- Testing schedule and timeline

## Key Activities
1. Analyze requirements and identify testable items
2. Define testing scope and objectives
3. Identify risks and testing challenges
4. Allocate resources and define roles
5. Create test schedule
6. Define entry/exit criteria
